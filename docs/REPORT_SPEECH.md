## 开场（约 40 秒）

各位老师好。本项目做的是 **ICU 床位资源的动态调度**。

我们的**总目标**可以概括成六个字：**可审计、可对照、可滚动**。

- **可审计**：为什么这张床分给这个病人，能说清楚，硬约束可检查。  
- **可对照**：换算法、换紧迫度、换滚动策略时，必须在同一批病人、同一套床位资源上比。  
- **可滚动**：病人入出转变化后，系统能再决策，而不是只给一张静态排床表。

整条业务链是：

**MIMIC 临床数据 → 仓内 SOFA / GBDT 病情紧迫度 → 硬约束 CP-SAT 分床 → 多种多目标权衡方式 → 滚动再优化 → 公平对照与演示界面。**

说明一点边界：本课题是**独立调度仓**，**不读取**另一个预警项目的风险分；强化学习只做离线对照，**不宣称**已经在 MIMIC 上完成床旁在线学习。

---

## 一、约束（我们守什么规矩）

### 1. 问题约束（临床业务）

- 一人一床；隔离床、呼吸机、病区布局有上限。  
- 隔离需求、呼吸机需求目前用**可配置规则近似**，并在解释报告中披露——**不是**临床金标准设备台账。  
- 目标里的 `wait` 键表示「已服务的优先级总和」，**不是**真实候诊分钟数（文档已写明）。

### 2. 方法约束（研究纪律）

- 生产默认策略是 **CP-SAT**，保证分配可解释。  
- 对照必须 **同候选池 stay_ids + 同资源布局**，禁止「各跑各的池子」假对比。  
- **禁止**把外部 `risk_score` 硬耦合进优先级。  
- **禁止**在无轨迹协议时宣称 online MIMIC-PPO。

### 3. 工程约束

- dump / 模型权重 / 轨迹产物不入 Git；评测划分用 calib/eval，不是随意 train/test 口号。

这些约束本身也是贡献：**把能做的和不能装的分开说清楚**，避免伪学术。

## 二、目标（我们要做成什么）

| 层级 | 内容 |
|------|------|
| **总目标** | 在 MIMIC 可复现设定下，交付可审计、可对照、可滚动的 ICU 分床系统与评测协议 |
| **功能目标** | 端到端：数据 → 紧迫度 → 优化 → 滚动 → Streamlit/MCP 演示 |
| **方法目标** | 同硬约束下对比加权和 / 词典序 / ε-约束；证明紧迫度变化会改变分床；量化滚动再优化相对贪心填床 |
| **非目标** | 不发明新通用求解器；不做床旁 RCT；不替代医院 HIS 上线 |

## 三、价值（做成了有什么用）

### 实用价值

1. **给医护/管理者一面「能问为什么」的分床镜子**：推荐结果可回溯到硬约束与目标权衡，而不是黑盒打分。  
2. **压力场景可试算**：床位紧张、隔离不足、高 SOFA 池等，可用同一套模型扫一遍。  
3. **接口可接演示与工具链**：Streamlit 交互台 + MCP `optimize_beds`，便于课设展示与后续集成。

### 研究与教学价值

1. 提供 **MIMIC 上可复现的分床协议**：后人换优先级模型或目标权重，不必从零拼 Demo。  
2. 把「预测好看」和「决策变了」拆开验收（见下节创新 H5）。  
3. 诚实披露简化假设，方便老师和评审定位真实贡献边界。

### 一句话意义

> 我们交的不是「又一个调用了 OR-Tools 的作业」，而是一套**能解释、能对比、能滚动**的 ICU 分床研究与演示平台。

## 四、创新性：和「过去旧做法」比，多了什么

我们**不**把「使用了谷歌 OR-Tools」或「训练了 PPO」说成创新。  
先说清：**过去常见怎么做 → 缺什么 → 本仓多出来的是什么。**

### 4.1 新旧对照表（答辩主表）

| 维度 | 过去常见 / 旧版演示 | 本仓现在有的（之前没有或未做成证据） |
|------|---------------------|--------------------------------------|
| 分床决策 | 按紧迫度排序「能塞就塞」；或黑盒推荐 | **完整 0-1 分配模型** \(x_{ib}\)：一人一床 + 隔离床 + 呼吸机上限，CP-SAT 可证可行/最优 |
| 多目标 | **只调一组 λ** 加权和，一个折中解说不清谁优先 | **同硬约束**下三种机理：加权和 / **词典序** / **ε-约束**，可复现对照（H4） |
| 高危优先 | 靠把权重调大「碰巧」照顾高危 | 显式目标 \(f_{\mathrm{hr}}\)=已分配 SOFA≥10 人数；词典序可锁层级 |
| 预测层 | 报 Spearman、「模型准」就结束 | **H5**：换 SOFA/公式/GBDT 后比**分床名单 Jaccard**——预测必须接到决策 |
| 滚动 | 仿真动画好看，无对照臂 | **H6**：同种子下「每步再优化」vs「只往空床贪心塞」 |
| 评测 | 各方法各抽一批病人，数字不可比 | **Fair**：同一 `stay_ids` + 同一床位/隔离/呼吸机布局（H3） |
| 语义 | `wait` 等键名含糊 | **披露**：`wait`=priority 总和≠候诊分钟；overload=高危落非隔离床 |
| 外部耦合 | 易接预警 risk 当分 | **禁止**接 decision `risk_score`；紧迫度仓内自洽 |
| RL | 晒训练曲线当交付 | PPO **仅离线对照**；默认仍 CP-SAT；不宣称 online |

### 4.2 一句话：「之前没有的」

> **之前没有的是：在同一套可审计硬约束上，把「多种决策机理 + 预测→分床闭环 + 滚动再优化对照 + 公平评测协议」做成可复现证据链；而不是再调一组权重或再训一条曲线。**

### 4.3 假设编号（与证据入口）

| 编号 | 创新点 | 证据 |
|------|--------|------|
| H4 | 三种多目标机理对照 | 多目标页 · bake-off · `S2_MULTI_OBJECTIVE` |
| H5 | 预测→决策 Jaccard | `run_pto_ablation`（本地曾见 ≈0.11） |
| H6 | 滚动再优化对照 | `run_rolling_contrast` |
| H3 | Fair 同池同资源 | 对照页 · S3 多 episode |

**相对近刊（谦虚）：** SciRep 2023 等强在不确定下元启发式；我们切口是精确 CP-SAT + MIMIC 管道 + 上述协议，**不宣称整体 SOTA**。

## 五、模型、算法与数学公式（口播版）

> 老师若问「你们到底优化什么」，按下面讲；板书用附录。

### 5.1 分配模型（CP-SAT）

决策变量 \(x_{ib}\in\{0,1\}\)：患者 \(i\) 是否分到床 \(b\)。

硬约束（核心）：

\[
\sum_i x_{ib}\le 1,\quad
\sum_b x_{ib}\le 1,\quad
\text{隔离患者只能进隔离床},\quad
\text{需呼吸机人数}\le V。
\]

软目标（向量，不是单一黑盒分）：

\[
\begin{aligned}
f_{\mathrm{occ}}&=\sum_{i,b}x_{ib}
&&\text{占用（max）}\\
f_{\mathrm{hr}}&=\sum_{i:\mathrm{SOFA}_i\ge 10}\sum_b x_{ib}
&&\text{高危服务数（max）}\\
f_{\mathrm{pri}}&=\sum_{i,b} w_i x_{ib}
&&\text{优先级总和（max；键名 wait）}\\
f_{\mathrm{ov}}&=\sum_{\substack{i\in\mathcal{H}\\ b\notin\mathrm{ISO}}}\mathrm{SOFA}_i\,x_{ib}
&&\text{高危落普通床（min）}
\end{aligned}
\]

### 5.2 三种算法怎么用这些目标

**（1）加权和（旧基线）**

\[
\max\;\sum_k \lambda_k \tilde f_k
\quad(\text{max 项为正，min 项为负})
\]

**（2）词典序（本仓强化）**  
先最优占用，再锁住该值，再最优高危人数，再 priority……层级写死，不靠 λ「碰巧」。

**（3）ε-约束（本仓强化）**  
例如 \(\max f_{\mathrm{pri}}\)，同时 \(f_{\mathrm{occ}}\ge\varepsilon_{\mathrm{occ}},\;f_{\mathrm{hr}}\ge\varepsilon_{\mathrm{hr}},\;f_{\mathrm{ov}}\le\varepsilon_{\mathrm{ov}}\)。  
换 \(\varepsilon\) 可扫 Pareto；阶段 3 可算 Hypervolume。

### 5.3 紧迫度（进 \(w_i\) 之前）

\[
u_i=1+\frac{\mathrm{SOFA}_i}{10}+\frac{2}{1+\max(\mathrm{LOS}_i,1)}
\quad\text{（公式基线；GBDT 拟合其平滑版）}
\]

H5：同一 CP-SAT，只换 \(w_i\) 来源，比分配集合

\[
J(A,B)=\frac{|A\cap B|}{|A\cup B|}。
\]

### 5.4 算法栈一览

| 模块 | 算法 / 模型 | 角色 |
|------|-------------|------|
| 紧迫度 | SOFA 规则 · 构造公式 · GBDT/GBR | 预测层 |
| 分床 | CP-SAT 0-1 整数规划 | **默认决策** |
| 多目标 | Weighted Sum / Lex / ε-Constraint | 决策机理 |
| 滚动 | 滚动时域 + 每步再求解 | 动态 |
| 对照 | 贪心 ·（可选）MaskablePPO | 基线 / 研究轨 |

## 七、学术权威性（怎么立得住、哪里要谦虚）

### 立得住的部分

1. **问题来自真实公开数据设定（MIMIC）**，不是纯玩具随机数。  
2. **方法栈有文献锚点**：约束规划分床、多目标 ε/词典序、Predict-then-optimize、滚动时域——均有经典与近刊可对标（见 SOTA_SURVEY）。  
3. **假设可证伪**：H4–H6 都有可复现命令与报告，打平也如实写。  
4. **评测纪律**：calib/eval、同池公平对照，避免「调参集冒充泛化」。

### 必须谦虚的部分

1. **不是顶会级新算法**：CP-SAT、加权/Lex/ε、PPO 均为既有方法。  
2. **隔离/呼吸机需求仍是启发式**，权威性止于「可披露的工程近似」。  
3. **无床旁 RCT / 无多中心外部验证**，不能说临床有效性已证明。  
4. **权威性来自「可审计协议 + 可复现证据」**，不是来自「我们全面领先文献」。

### 给老师的权威性一句话

> 本项目的学术立场是 **应用运筹与可复现系统研究**：在公开数据上把可解释分床做成可对照平台，并用 H4–H6 给出可检查证据；我们接受「方法本身不新」，但坚持「问题设定、评测协议与诚实边界是清楚的」。

## 八、收尾（约 25 秒）

综上：  
**约束**守可解释与公平对照；  
**目标**是可审计、可对照、可滚动的 ICU 分床；  
**价值**在研究可复现与管理可解释；  
**创新**相对旧做法：同约束上的 Lex/ε、预测→名单 Jaccard、滚动对照臂、Fair 评测——这些是以前演示里缺的证据链；  
**模型**上是 \(x_{ib}\) CP-SAT + 多目标向量 + 仓内紧迫度；  
**实用**于演示与离线试算；**学术上**对标而不冒充 SOTA。
