# 学术价值与够格判断（诚实版）

> 2026-10-09 · 对内 SSOT · **禁止**对外说「首创 / SOTA」除非本页假设验收齐全  
> 总目标主线：[MASTER_NARRATIVE.md](MASTER_NARRATIVE.md)

## 一句话判断

| 场景 | 够不够格 |
|------|----------|
| 本科课设 / 系统演示答辩 | **勉强够**：有完整链路 + 多目标机理 + 公平对照 + 诚实边界 |
| 「学术创新项目」/ 可投运筹或医疗 AI 短文 | **以 H7 为主主张**：RFCC 新机制 + CARE/UHRM 新指数；H4–H6 为证据链 |
| 顶会通用新求解器 | **不够**：未提出新 CP 求解器；创新在 **ICU 场景机制与指标** |

## 项目真正创造的意义（完成后）

1. **可审计的 ICU 分床决策链**：MIMIC → SOFA/GBDT 紧迫度 → 硬约束 CP-SAT → 滚动再优化 → 可视化/MCP。医院场景要「为什么这张床」，不是再堆一个黑盒。
2. **同约束下的决策机理对照**：不是「用了 OR-Tools」，而是加权 / 词典序 / ε 在同一批人、同一套床上可复现对比（H4 + bake-off）。
3. **公平评测纪律**：同池 stay_ids + 同资源布局，才谈贪心/CP/PPO；小池打平就承认打平（H3）。
4. **诚实边界本身是贡献**：隔离/呼吸机需求启发式、wait≠候诊时长、不宣称 online MIMIC-PPO——避免伪学术。

## 相对文献的位置（不装领先）

| 文献方向 | 他们强在 | 我们切口 |
|----------|----------|----------|
| ICU 床位两阶段多目标 + NSGA-II（如 SciRep 2023） | 不确定下元启发式 Pareto | **精确 CP-SAT** + 可解释硬约束 + MIMIC 特征管道 |
| 手术室 ε-约束 / 鲁棒 MSS | 不确定性与下游 ICU | 我们聚焦 **ICU 床位分配**，非 OR 主排程 |
| Predict-then-optimize 通论 | 决策导向训练 | 我们做 **仓内 PtO 决策质量消融（H5）**，不接外部预警分 |
| 约束 RL | 在线策略 | 我们默认 CP-SAT；RL 仅离线对照 |

## 原先缺口（为何「不够创新」）

- 优先级消融停在 Spearman / top-k，**没有证明「预测变了 → 分床结果变了」**。
- 滚动仿真有工程，**缺少「滚动再优化 vs 一次性/贪心填床」的量化增益**。
- 方法贡献偏「标准多目标 + 工程系统」，答辩易被打成拼接。

## 补强假设（答辩可绑）

| ID | 假设 | 相对谁 | 改什么 | 验收 |
|----|------|--------|--------|------|
| **H5** | 不同紧迫度模型会改变 CP-SAT 分配结果（决策质量，不只相关性） | 只报 Spearman | 同池注入 SOFA/公式/GBDT → 再求解 | `run_pto_ablation` 表 |
| **H6** | 滚动再优化相对「只入院填床、不重优化」改善占用质量/病情均值 | 静态或贪心滚动 | `reoptimize` 开关对照 | `run_rolling_contrast` 表 |

## 对外怎么说价值（老师/评审）

> 我们不宣称发明了新求解器。贡献是：**在 MIMIC 可复现设定下，把「可审计约束分床」做成可对照的研究平台**——多目标机理、预测→决策闭环、滚动增益、公平评测与局限披露。完成后的意义是：后续人可以在同一协议上换优先级模型或鲁棒目标，而不是从零拼 Demo。
